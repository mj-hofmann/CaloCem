# ProcessingParameters

`ProcessingParameters` holds all analysis settings, grouped by topic. See
[Processing Parameters](../processing-parameters.md) for a guide to the
individual groups. Import it with `from calocem import ProcessingParameters`.

::: calocem.ProcessingParameters
    options:
      show_root_heading: true
      show_source: false
      members_order: source
      filters: ["!^_"]
