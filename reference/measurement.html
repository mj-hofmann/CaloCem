    Measurement¶

    Measurement loads the calorimetry files of a folder and provides all plotting and analysis methods. Import it with from calocem import Measurement.

    calocem.Measurement ¶

    folder: Optional[Union[str, Path]] = None,
    show_info: bool = True,
    regex: Optional[str] = None,

    new_code: Optional[bool] = None,

    save_cache: bool = False,

    Isothermal heat flow calorimetry data of one or more samples.

    A Measurement reads all calorimetry files of a folder into one long-format DataFrame and provides methods for plotting and analysing the samples.

    Parameters:

    Name Type Description Default
    folder str or Path

    Folder with the exported calorimetry files (.csv or .xls). Subfolders are not searched. If None, an empty Measurement is created.

    		 None
    show_info bool

    Print information while loading, by default True.

    		 True
    regex str

    Regular expression matched against the beginning of the file names; only matching files are loaded.

    		 None
    auto_clean bool

    Drop rows without heat flow values and merge differently named temperature columns into temperature_c, by default False.

    		 False
    cold_start bool

    If True (default), read the files. If False, read _data.pickle and _info.pickle from the current working directory instead (see save_cache).

    		 True
    processparams ProcessingParameters

    Default processing parameters for all analysis methods. The downsample settings are applied while loading.

    		 None
    new_code bool

    Deprecated, has no effect.

    		 None
    processed bool

    Read plain CSV files previously written from :meth:get_data, by default False.

    		 False
    metadata_path str or Path

    CSV or Excel file with one row of metadata per sample, see :meth:add_metadata_source.

    		 None
    metadata_id_column str

    Column of the metadata file holding the sample names. Required together with metadata_path.

    		 None
    save_cache bool

    Write _data.pickle and _info.pickle to the current working directory after loading, by default False. Prefer :meth:save.

    		 False

    Raises:

    Type Description
    AutoCleanException

    If auto_clean fails.
    ColdStartException

    If cold_start=False and no cache files are found.

    Examples:

    >>> from calocem import Measurement, ProcessingParameters
>>> tam = Measurement(folder="calo_data", regex=r"opc_.*", show_info=False)
>>> tam.get_sample_names()
['opc_1', 'opc_2']

    save ¶

    save(path: Union[str, Path]) -> None

    Save this Measurement to a named pickle file for fast reloading.

    The whole object is stored, so the processed (e.g. downsampled) data, info, added metadata and processparams are all preserved and the object can be restored with :meth:load in a downstream script.

    This file is a convenience cache, not an archive: the raw source files remain the source of truth. A file that fails to load -- for instance because it was written by an incompatible calocem version -- can always be regenerated by re-running from the original folder.

    Parameters:

    Name Type Description Default
    path str or Path

    Destination file. The .pkl extension is recommended to make the pickle format explicit.

    		 required

    get_deconvolution ¶

    get_deconvolution(
    processparams: Optional[ProcessingParameters] = None,
    target_col: str = "normalized_heat_flow_w_g",
    age_col: str = "time_s",
    regex: Optional[str] = None,
    n_peaks: Optional[int] = None,
    peak_shape: str = "lognormal",
    baseline_mode: Optional[str] = None,
    relative_intensity_upper_bounds: Optional[
        list[float]
    ] = None,
    peak_width_upper_bounds: Optional[list[float]] = None,
    show_plot: bool = False,
    ax=None,
) -> pd.DataFrame

    Fit the heat flow of each sample as a sum of peaks plus a baseline.

    The data after processparams.cutoff.cutoff_min is fitted with n_peaks lognormal or Gaussian components by constrained least squares. If the fit with the requested baseline fails, simpler baselines are tried.

    Parameters:

    Name Type Description Default
    processparams ProcessingParameters

    Processing parameters. If None, the parameters of the Measurement are used.

    		 None
    target_col str

    Column with the heat flow, by default "normalized_heat_flow_w_g".

    		 'normalized_heat_flow_w_g'
    age_col str

    Column with the time in seconds, by default "time_s".

    		 'time_s'
    regex str

    Regular expression; only samples whose name matches are analysed.

    		 None
    n_peaks int

    Number of components. Defaults to processparams.deconvolution.n_peaks.

    		 None
    peak_shape str

    "lognormal" (default) or "gaussian".

    		 'lognormal'
    baseline_mode str

    "constant", "linear", "chebyshev" or "none". Defaults to processparams.deconvolution.baseline_mode.

    		 None
    relative_intensity_upper_bounds list of float

    One value per component in (0, 1]: maximum share of the total amplitude.

    		 None
    peak_width_upper_bounds list of float

    One value per component: maximum width.

    		 None
    show_plot bool

    Plot the data, the components and the fit, by default False.

    		 False
    ax Axes

    Axes to draw into.

    		 None

    Returns:

    Type Description
    DataFrame

    One row per sample and component with component (from 1), amplitude (W/g), center_time_s, peak_time_s, width, component_area (J/g), component_area_fraction, the fit quality fit_r2 and fit_rmse (W/g) and the baseline coefficients.
    Notes

    For lognormal components, width is the dimensionless standard deviation of ln(t) and center_time_s the median; for Gaussian components both are in seconds. A component with an amplitude close to zero has a meaningless peak_time_s.

    get_mainpeak_params ¶

    get_mainpeak_params(
    processparams: Optional[ProcessingParameters] = None,
    target_col: str = "normalized_heat_flow_w_g",
    age_col: str = "time_s",
    show_plot: bool = False,
    save_plot: bool = False,
    plot_type: str = "mean",
    regex: Optional[str] = None,
    plotpath: Optional[Path] = None,
    ax=None,
    method: str = "mean",
    monochrome: bool = False,
    marker_size: float = 1.0,
) -> pd.DataFrame

    Characterize the main hydration peak: slopes, onset times and peak values.

    With method="mean" (default) two analyses are combined:

    • maximum slope: the maximum of the time derivative of the heat flow (after optional smoothing), and the onset where the tangent at this point meets the dormant heat flow or the time axis;
    • mean slope: a tangent averaged over the ascending flank between slope_analysis.flank_fraction_start and flank_fraction_end of the peak height, and its onset.

    With method="ascending" the slope of the first ascending segment up to a threshold (slope_analysis.first_ascending_*) is determined instead. This is the only analysis that honours sample parameter rules.

    In both cases the dormant period (:meth:get_dormant_period_heatflow) and ASTM C1679 (:meth:get_astm_c1679_characteristics) values are added.

    Parameters:

    Name Type Description Default
    processparams ProcessingParameters

    Processing parameters. If None, the parameters of the Measurement are used.

    		 None
    target_col str

    Column with the heat flow, by default "normalized_heat_flow_w_g".

    		 'normalized_heat_flow_w_g'
    age_col str

    Column with the time in seconds, by default "time_s".

    		 'time_s'
    show_plot bool

    Plot the analysis for each sample, by default False.

    		 False
    save_plot bool

    Save each plot as PNG to plotpath, by default False.

    		 False
    plot_type str

    For method="mean": show the "mean" (default) or "max" slope analysis.

    		 'mean'
    regex str

    Regular expression; only samples whose name matches are analysed.

    		 None
    plotpath Path

    Folder for save_plot.

    		 None
    ax Axes

    Axes to draw into. If None, one figure per sample is created and shown.

    		 None
    method str

    "mean" (default) or "ascending".

    		 'mean'
    monochrome bool

    Draw all markers in black, by default False.

    		 False
    marker_size float

    Scale factor for marker sizes, by default 1.0.

    		 1.0

    Returns:

    Type Description
    DataFrame

    One row per sample. For method="mean" the columns include gradient_from_max_slope (W/g/s), max_slope_time_s, onset_time_s_from_max_slope, onset_time_min_max_slope, gradient_of_mean_slope (W/g/s), mean_slope_time_s, onset_time_s_from_mean_slope, peak_time_s, normalized_heat_flow_w_g_at_peak, dorm_time_s, normalized_heat_flow_w_g_dormant and astm_time_s, together with the heat flows and heats at these times. For method="ascending" the slope is in gradient_of_first_ascending_slope_to_fraction_of_max and the onset in onset_time_s_from_first_ascending_slope.

    Raises:

    Type Description
    ValueError

    If method is not "mean" or "ascending".

    Examples:

    >>> processparams = ProcessingParameters()
>>> processparams.spline_interpolation.apply = True
>>> result = tam.get_mainpeak_params(processparams, show_plot=True, plot_type="max")
>>> result[["sample_short", "gradient_from_max_slope", "onset_time_s_from_max_slope"]]

    apply_tian_correction ¶

    apply_tian_correction(
    processparams: Optional[ProcessingParameters] = None,
) -> None

    Apply Tian correction to the heat flow data.

    Corrects the measured heat flow for the thermal inertia of the calorimeter using one or two time constants (tau1, tau2) from processparams.

    Single time constant (tau2 = None): hf_corrected = dHF/dt * tau1 + HF

    Dual time constants: hf_corrected = dHF/dt * (tau1 + tau2) + d²HF/dt² * tau1*tau2 + HF

    Results are written to three new columns: - normalized_heat_flow_w_g_tian - gradient_normalized_heat_flow_w_g - normalized_heat_j_g_tian

    Parameters:

    Name Type Description Default
    processparams ProcessingParameters

    Processing parameters containing time_constants.tau1 and time_constants.tau2. Uses instance processparams if not provided.

    		 None
